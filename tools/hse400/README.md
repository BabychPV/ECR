# tools/hse400 — шаблон HSE400 «Компонентний склад газу»

Річний шаблон: один документ на рік, місяці — колонки `M01`…`M12`. Аркуш `GasComposition`, шість таблиць
(код таблиці = префікс AF): `FG_Makat`, `FG_HMB`, `LPG_HMB`, `FG_Export`, `FG_Internal`, `LPG_Internal`.

| Файл | Що це |
|---|---|
| `hse400-model.json` | модель: таблиці, рядки, підписи en/ru (згенеровано з вивантаження AF `Methodologies\HSE400\V1`) |
| `Hse400Model.Lib.ps1` | читання й перевірка моделі, місячні колонки |
| `Hse400Stand.Lib.ps1` | ціль, охорона стенда, виклики API |
| `Build-Hse400Template.ps1` | шаблон + річний проєкт + документ |

## Договір рядків (спільний із модулем місячних колонок)

- рядок **вводу**: `RowKey` = код компонента AF (`Methane`, `IC4_1`, …); аргумент методики — `GCV_HSE400_<таблиця>_<RowKey>`;
- **розрахунковий** рядок: `RowKey` = `F_<X>` для формули `HSE400_<таблиця>_<X>`, лише читання;
- модуль не читає рядки `F_` як ввід і не пише в рядки вводу.

Префікс `F_` потрібен, бо ім'я формули збігається з кодом вводу (`Nitrogen` у `FG_Makat`/`FG_Export`, вісім
кодів у `*_Internal`). Рядків вводу / розрахункових: 15/38, 34/58, 34/58, 16/41, 38/65, 38/65.

## Запуск

```powershell
powershell -File tools\hse400\Build-Hse400Template.ps1 -BaseUrl http://localhost:5094 -Database <база> `
    -ConfirmStand <база> -CredentialFile <шлях поза репозиторієм> -Year 2026 [-Stage Template|Project|All] [-PreviewOnly]
```

Лише локальна адреса; `-ConfirmStand` має дорівнювати `-Database`; файл облікових даних — один рядок
`користувач<TAB>пароль` поза git-worktree. Скрипт не створює облікових записів, ролей і баз. Повторний запуск
нічого не змінює: опублікована версія не чіпається, наявні проєкт і документ не дублюються. Стан — `out/` (не в git).

## Припущення й борг

- підписи рядків — як у старій системі, тож ввід і похідний рядок можуть мати однаковий текст (`Nitrogen` і `F_Nitrogen`);
- статичні довідкові колонки (молекулярна вага, теплота згоряння компонента) не перенесено;
- правил перевірки немає: правило задається на колонку, а в місячній колонці стоять рядки різної природи
  (% об., г/м3, температура); сума складу видна в рядку `F_TotalSum…`;
- відповідність рядків `Vog`/`Vo`/`VoH2O` рядкам звіту підтверджується числами на прийманні (HSE400.Year);
- звірка моделі з вивантаженням AF — разова локальна (вивантаження не лежить у git), у CI її немає. Результат
  11.11: із 500 рядків 496 мають ім'я `HSE400_<таблиця>_<X>` у вивантаженні; чотири рядки вводу
  (`Temperature` у `FG_HMB`/`LPG_HMB`, `TotalMercaptanSulphur` у `FG_Internal`/`LPG_Internal`) є в AF як атрибути
  вводу, але формули HSE400 на них не посилаються — їх лишено для вводу, як у старій формі.
