## 1. Що і навіщо
- Дослівно: «Ціль розробити інтерфейс для додавання зміни та видалення цих даних в нашій системі. Додай в бічній панели пункт. Також має бути підтримка версій газів…»
- Споживач: методологіст/адмін (бічна панель → Gas composition); розрахунки факелів (методології) читають склад з ECR.
- Робоча папка: `C:\ecr-wt\gas-composition`; бази: `G:\EcrData`
- Умова зупинки: потрібен токен міграції до готовності сусідніх lane; рішення, що змінює розрахунок.

## 2. Критерії приймання
| AC | Що спостерігаємо (вхід → результат) | Доказ: тест / команда / live | SHA |
|----|-------------------------------------|------------------------------|-----|
| AC-0 | live: у бічній панелі пункт складу газів; додати/змінити/видалити версію складу потоку; історія версій видна | live: екран людини | |
| AC-1 | перенос FLERT → ECR без втрат (кількості й контрольні суми по таблицях) | скрипт на копії, ×2 ідемпотентно | |
| AC-2 | розрахунки отримують ті самі входи до/після перемикання | паритет на копії live | |
| AC-3 | валідація (сума компонентів, перекриття дат, незмінність використаних версій), права, аудит змін | тести + мутації | |
| AC-4 | UI охайний: світла/темна, 375 px, клавіатура, a11y | vitest + a11y + e2e + знімки | |
