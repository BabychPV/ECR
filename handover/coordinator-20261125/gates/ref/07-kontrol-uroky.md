# Контроль, звіти, уроки

## Щогодини (:13) — один виклик у cron, не з пам'яті
```
python H:\ECR\.sync-local\gates\hourly.py --repo H:\ECR --roots H:\ECR-wt H:\ECR-worktrees H:\ECR\.claude\worktrees C:\ecr-worktrees F:\ecr-wt
```
Чому в cron: 23.11 усі скрипти запустили один раз при встановленні, а щогодинні контролі 24.11 їх уже не викликали — картки застаріли, LIVE-SHA лишився на W15y, диск H: дійшов до 0 ГБ.

hourly.py друкує лише [!] (чисто — один рядок «OK»):
- LIVE-SHA у файлі ≠ версія, що реально працює на стенді (процес на :5094 → build.done);
- картки: статус проти git, «СТАТУС ВІДСТАЄ», AC без SHA, «НЕ ПОЧАТО?», простій, прийнято й забуто;
- «ГІЛКА БЕЗ КАРТКИ» — активна lane-гілка, для якої картки немає;
- нові позначки робочих копій і сироти (розібрані не повторюються);
- диск робочих копій < 20 ГБ.
Кожну [!] — розібрати в цьому ж контролі: незакомічене без живого агента — спершу зберегти; нічого не видаляти. Разом із hourly — `ctl.ps1` (CI, черга GitHub).

**Розібрані позначки робочих копій:** після тріажу (як `reports\wt-triage-1123.md`) — один раз `python gates\wt_audit.py --repo H:\ECR --roots … --ack`. Далі hourly показує лише нове. Брудну основну папку «розібрати» не можна — вона показується завжди.

## Кожні 2 години (:37) — ретроспектива
- **Пропуск** = помилка, спіймана на дорожчому кроці, ніж могли (E0…E10). Для кожного: на якому кроці мали спіймати, скільки годин CI чи репетиції коштував.
- Кожен пропуск → **нова перевірка** або явне «перевірки бути не може, бо …». Куди додано: рядок картки, пункт довідника ref\, прапорець скрипта, тест у `test_gates.py`. Урок без перевірки — лише запис.
- Формат у memory/self-improve-practices.md:
  `Урок <N> (<дата>): <що> · мали спіймати на E<k> · нова перевірка: <що> · де: <файл/рядок>`
