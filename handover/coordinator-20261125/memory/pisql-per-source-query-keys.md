2026-09-29 людина прямо в чаті: «Додай ключ джерела бо ми може звертатися до різних баз на одному AF сервері».

**Why:** текст RTQP-запиту (напр. `PiSqlClient:ElementListQuery`, D-212 PR-1) містить ім'я бази AF; кілька джерел ECR на один AF-сервер, але різні бази — один спільний текст не підходить.

**How to apply:** будь-який новий ключ запиту PiSqlClient шукати спершу на рівні джерела, потім спільний; не вводити нових лише-глобальних налаштувань RTQP. Факт про світ замовника — «Аудит» заносить у D-212. Див. [[role-development-all-zones]].
