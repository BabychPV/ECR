16.11 (квіз про дублі документів після B150) людина: «наприклад для Land template це можливо — різні HSE з різними вкладками; для 400 та 401 ні; тобто це має бути конфігурація в темплейті яка це перевіряє/дозволяє».

**Why:** POST /documents приймає два одночасні створення, і виходять два документи. Клієнт уже захищений (B145), але правило «один чи кілька» залежить від шаблону.

**How to apply:**
- PLAN B151: прапорець шаблону «один документ на проєкт+період» / «кілька».
  - Сервер перевіряє атомарно, повертає 409 з посиланням на наявний документ.
  - HSE400 і HSE401 — «один»; Land — «кілька»; дефолт для наявних шаблонів — як зараз.
- Перед увімкненням на live — read-only перевірка наявних дублів HSE400/401.
- Зв'язок із B80: завантажувач HSE400 обирає «найбільший id»; з правилом «один» ця неоднозначність зникає.
