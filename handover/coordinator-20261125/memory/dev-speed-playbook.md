Людина (07.10 05:45Z, тред координації): «зроби всі необхідні оптимізації для пришвидшення розробки зі збереженням якості і зберегай це в довгостроковій памʼяті».

**Why:** ніч 06→07.10 показала, що час іде не на код, а на черги: один інтегратор («Аудит»), локальний e2e 46 хв, CI-черга раннерів, ручні релеї, диск. Якість (безпека, e2e, upgrade) не знижуємо — переносимо перевірки паралельно й на CI.

**How to apply (чинні правила):**
1. **RC ділити:** серверний/безпековий RC нарізається одразу; UI-пачка йде окремим RC, якщо нема зеленої вершини + e2e + «Макет». Безпека не чекає UI.
2. **e2e на CI-раннері** (`.github/workflows/e2e-stand.yml`, dispatch ref/grep + авто на PR з rc/**, ≈24 хв замість 46): Аудит ганяє e2e паралельно з рев'ю; локально — лише цільові -Grep. Workflow НЕ додавати в branch protection main.
3. **Хмарна лінія «готово» = e2e зачеплених екранів пройдено** (або чесно «не виконувалось»); «CI зелений» ≠ e2e зелений (e2e ci-exempt). Нові глобальні landmarks (nav) → grep по e2e/.
4. **База перезбірки фіксується хешем dev ДО старту**; очікування чужого пуша ≤30 хв, далі збирати від наявного dev і зводити конфлікт при зведенні. Серверну пачку (S1) пушити першою.
5. **Лист готовності** = гілка @хеш, «замінює X @hash», що прогнати, TIER; хмарі називати ЄДИНУ базу RC; один пуш на вичерпану lane (CI-черга).
6. **Диск:** контроль кожні 15 хв включає C: (<15 ГБ → наказ знімати влиті worktree) і H: (<40 ГБ → прибрати EcrTest_*); worktree/стенди лише `H:\ecr-wt\<ім'я>` або `F:`; власник знімає worktree після влиття (`git worktree remove` без --force). Агент-чистильник при блоці класифікатора зупиняється, не обходить.
7. **Паралельні легкі лінії хмари без .NET** (a11y, звірка з макетом, user-docs, тести-сторожі без запуску, e2e-списки) запускати одразу після batch — вони не блокують RC; тести-сторожі з хмари прогонює Аналіз.
8. **Ретро кожні ~2 год** фактами (git/gh/list_sessions), виправлення впроваджувати самому; табло оновлювати лише коли змінились картки (інакше лише meta/state).
9. **Релеї:** хмара→Аудит йде через мене: одне речення + хеш + шлях файлу; повний текст не пересилати (бібліотека проєкту `audit/...`).
10. **Рішення на межі безпеки** (R-6, Q-177) фіксувати в реєстрі D-nn і known limitations одразу, не залишати «відкритим питанням» під час RC.
