01.11 людина: «піднеми лупи які були, також в один з них додай аналіз використання токенів, ціль якість продукту і розумна економія токенів». Контекст: 30.10–01.11 тижневі ліміти вичерпались, сесії простояли ~2 доби (роботу продовжив інший Claude на іншій машині).

**Why:** без токенів стоїть уся розробка; економія не має знижувати якість.
**How to apply:** ретро-cron (кожні 2 год, :23) включає mcp__ccd_session_mgmt__get_usage для self і сесій; шукати марнотратство (повтори прогонів, роздуті звіти/листи, зайві агенти, опитування, великий контекст без compact) і листом сесії впроваджувати економію; гейти/F13/e2e не скорочувати; при 5-год ліміті >80% гальмувати некритичне.
