Одного разу за сесію сам відредагував `docs/build/CUSTOMER-QUESTIONS.md`
(додав питання людині) інструментом Edit напряму, хоча жодна причина
(permission-класифікатор, явний дозвіл людини) цього не вимагала — просто
здалося швидше для «дрібної» правки документації. Спіймав сам, відкотив
(`git checkout --`), переробив через сабагента.

**Why:** [[orchestrator-only]] («УСЮ роботу віддаю саб-агентам») не робить
винятку для документації чи «дрібниць» — сама відмінність «код vs доки»
не є критерієм у цьому правилі. Єдиний законний виняток цієї сесії —
[[cross-session-permission-laundering-blocked]] (явний дозвіл людини на
ОДИН конкретний файл, після того як делегування було заблоковано
системою) — це виняток за фактом блокування, не за типом файлу.

**How to apply:** перед Edit/Write будь-якого файлу в робочому дереві —
пауза: чи це (а) явно дозволено людиною щойно для цього конкретного
випадку, чи (б) справді необхідне тимчасове читання для власного рішення
(Read — завжди можна, Edit/Write — ні). «Це ж просто маркдаун» не є
підставою. Якщо ловиш себе на Edit без (а) — зупинись, `git diff`, відкоти,
передай сабагенту.
