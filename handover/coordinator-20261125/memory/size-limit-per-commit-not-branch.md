2026-09-29 RT-17a (рушій правил довідника) пішов одним комітом 37105a62 на ~2 тис. рядків, частка тестів 39 %. Пояснення агента: «чотири шляхи — upsert, пакет, CSV, збереження опису — не ділились без втрати доказу». «Аудит» (інтегратор) прийняв лише як свій одноразовий виняток. Він вказав, що ці чотири шляхи можна було дати чотирма комітами в ОДНІЙ lane-гілці: кожен коміт зі своїми тестами й зелений сам по собі.

**Why:** межа розміру в CLAUDE.md задана для порції, яку читає інтегратор. Lane-гілка може нести кілька порцій, тож «не ділиться» — не аргумент для одного коміту.

**How to apply:** у промпті агента для великого кроку прямо писати: «один коміт на шлях / шар, кожен ≤ межі й зелений сам по собі (build + свої тести)». Порядок комітів: рушій і модульні тести → кожен шлях інтеграції окремо → контракт [CHORE] останнім. Пов'язане: [[dev-rules]], [[integrator-audit-lanes]].
