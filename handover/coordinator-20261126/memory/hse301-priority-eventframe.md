2026-09-29, 15:49 людина через координатора сказала: EventFrame забираємо через view PI SQL, і загалом більшість даних іде через вбудовані view PI SQL. Мітки FLERT — UTC, A7 закрито. Корпус методологій AF «ще не час», але механізм імпорту має бути, а посилання `!Code` на Common мають працювати.

Черга HSE301, затверджена координатором:
1. L — резолвінг бібліотечних формул. Першим комітом іде [FIX] formulaNotFound; інтегратор вимагає тест еквівалентності та тест циклу під час виконання.
2. Ланцюжок EventFrame: F4e (порт + читання PI SQL + ключі на джерело + UTC + типи) → F9 (мапінг M5) → типізований запис рядка → SourceEventSyncJob → межі події як вікно агрегату (A1/A4) → UI/API (A6). Широку форму й ієрархію — лише після фактів замовника.
3. V — імпорт методологій JSON-пакетом.
4. RT-23b / 24 / 25.
Паралельно: блок версії шаблону в обробниках прив'язок методологій, коли C5 «Безпеки» буде у вершині.

**Why:** людина назвала view PI SQL основним каналом даних. EventFrame у коді немає зовсім, і саме це блокує сценарій 301years.

**How to apply:** до відповіді людини діють такі дефолти: бібліотека береться «остання на дату» (без pin); формула бібліотеки обчислюється в контексті рядка викликача; EF-view у довгій формі; час UTC. Пов'язане: [[questions-go-to-coordinator]], [[machine-load-budget]].
