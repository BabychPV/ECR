Rules from the coordinator's retro, 16.11; they apply to all sessions.
- 416: a config key change → run the config tests locally before the push.
- 417: a new test helper or probe (e.g. stillOpenProbe, heldReads) must first be proven SENSITIVE: a mutation on a known-closed case goes red.
- 418: scripts take the absolute worktree path as a required argument. A stand run logs its FULL output to a file from the first attempt. Never build in H:\ECR.

**Why:** B149 F13 found that stillOpenProbe was green on a broken dialog (it clicked window 3 while the write was still loading). The B152 stand needed 5 runs because the output was filtered and the log was missing.

**How to apply:** the brief of any probe/helper agent includes a sensitivity mutation. The stand command uses `*> <scratchpad log>` from the start. Related: [[rules-410-411-mutation-build-ok-local-e2e-1116]], [[rule-401-mutate-every-branch-before-ready-1116]].
