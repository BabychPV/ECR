Людина 08.11, дослівно: «після правок 15:00 ти маєш протествати на живому стенді через UI як все працює, має бути інтрефейс та дії мають бути зрозуміли для користувача і також period перейменуй на Projects і налаштування проекту має бути внутрі сторінкі а не окремим розділом в панелі».

**Why:** UAT показав, що окремі розділи Periods / Project settings і незрозумілі стани плутають користувача; автотести й F13 цього не ловлять.
**How to apply:**
- Після кожного живого вікна з UI-змінами координатор сам проходить змінені сторінки на живому стенді в браузерній панелі під записом людини (без введення паролів), кожну кнопку, і пише людині, що працює і що ні.
- Дизайн: одна сторінка «Projects» → вкладки Periods / Settings / Lifecycle, причини недоступних дій видимим текстом.
