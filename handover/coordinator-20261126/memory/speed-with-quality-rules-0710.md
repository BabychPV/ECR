Пряме слово людини 07.10: «зроби всі необхідні оптимізації для пришвидшення розробки зі збереженням якості і зберегай це в довгостроковій памʼяті»; і дозвіл додати розділ «✎ 2026-10-07: швидкість зі збереженням якості» в CLAUDE.md («так дозволяю»).

**Why:** черги CI-раннерів (43 queued), диск C: 0,9 ГБ (збірки падали MSB3491), червоні e2e після UI-пачок при зеленому CI, ручні e2e по 46 хв.

**How to apply:** (1) серверний/безпековий RC нарізати одразу, UI — окремим RC, якщо нема зеленої вершини + e2e + «Макет»; (2) e2e — workflow `e2e-stand` на CI (dispatch ref/grep + авто на PR з rc/**), НЕ в branch protection main, локально лише цільові -Grep; (3) UI-lane «готово» лише з e2e зачеплених екранів; (4) база перезбірки lane = хеш dev до старту, чужий пуш чекати ≤30 хв; (5) worktree/стенди лише H:\ecr-wt\<ім'я> або F:\, власник знімає після влиття, C: <15 ГБ — негайна чистка; (6) блок класифікатора — зупинка, не обхід.
