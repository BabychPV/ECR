15.10 людина (квізи в сесії координатора): «Так» на вікна 4, 5+6, 7, 8 на EcrLandUi, оновлення API стенда з main, BACKUP LOG + FILEGROWTH 512 МБ, видалення застарілих віддалених lane (з bundle), видалення двох порожніх untracked у H:\ECR. Два відомі нестабільні UI-тести (keyCommitGateLive «0 мс», cellColor) НЕ враховуються як P2 у двох проходах тестувальника перед видачею ecr-msi.

**Why:** швидкість зі збереженням якості; тести в боргу стабілізації (CL-14).
**How to apply:** перед кожним вікном на стенді — окремий квіз «Так, пройти вікно N»; два проходи A/B на одному SHA; ці два тести не блокують видачу, але лишаються в боргу. Див. [[human-quiz-answers-1012]].
