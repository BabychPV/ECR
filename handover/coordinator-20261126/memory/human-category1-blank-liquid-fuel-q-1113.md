13.11 ~13:55Z, квіз після репетиції W15u. Без HSE400 у doc 96 лишається 19 помилок на місяць, і через C-1 вони блокують подання.

- **Category1** (група NAE з LAND_NAE_GROUP). Людина спитала «а для чого вони тобі, поясни чітко». Я пояснив: Category1 потрібна лише методології C11_11_02 для NAE 0883, а інші коди рахують C11_05/C11_10, і стара система для них лишала поле порожнім. Відповідь людини: **порожньо без помилки** (B88).
- **Рідке паливо** (Дизель, Бензин у T3_00; густина, теплота згоряння, H2S, меркаптани, які зараз беруться зі складу HSE400). Людина: «сформуй це питання для старої системи, і я запитаю і пізніше дам відповідь». Питання лежить у .sync-local\reports\Q-LEGACY-liquid-fuel-props-1113.md (B89, чекає відповіді).

**Why:** формули мають повторювати поведінку старої системи, і подання не можна блокувати помилками, яких у старій системі не було.

**Відповідь щодо рідкого палива — 13.11, ~15:15Z** (повністю: .sync-local\reports\A-LEGACY-liquid-fuel-props-1113.md):
- Ці 4 властивості зі складу HSE400 бере лише методологія 5.5 (газові котли).
- Дизель, гас і бензин рахуються методологіями 5.1–5.4, тож для них клітинки «не застосовується»: порожні й без помилки.
- 5.4 бере з констант методології в AF:
  - LHV k9 = 42.75 для дизеля, 43.12 для гасу;
  - сірку k11 = 0.025 для дизеля, 0.003 для гасу.
