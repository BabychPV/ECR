26.10 людина: «А, правило перенесення погоджую нехай це робить одна сесія але запускає сабтаски для першвидшення мені не потрібна бюрократия в сесіях». Варіант А: Monthly-проєкт, таблиці MonthsInColumns (потім Static) -- стовпець m читається/пишеться з екземпляра періоду m; правило перенесення: значення свого місяця, якщо порожньо -- останнє введене в будь-якій копії (aud.CellChange); apply на живому стенді -- окремим словом людини з бекапом. Виконавець -- ОДНА сесія (Аналіз) з паралельними сабагентами; рецензія Аудита лише швидка статична, без повторних кіл. **Why:** швидкість, менше узгоджень між сесіями. **How to apply:** для великих задач -- одна сесія-власник + сабагенти, не розкидати по сесіях.
