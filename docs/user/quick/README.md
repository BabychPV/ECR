# Короткі інструкції ECR Web — нові екрани (жовтень 2026)

Покрокові інструкції зі знімками для оновленого інтерфейсу: меню з групами,
«крихти» у верхній смузі, вибір періоду, дошка документів, майстер створення
документа, дерево таблиць та інспектор документа, палітра команд, клавіші,
адміністративні переліки й вузький екран.

| Файл | Про що |
|---|---|
| [01-navigation.md](01-navigation.md) | Меню з групами, крихти, згорнуте меню, палітра команд (Ctrl+K), вузький екран |
| [02-documents.md](02-documents.md) | Перелік документів: вибір періоду, фільтри й лічильники, Table / Board, Quick look, майстер «New document» |
| [03-document.md](03-document.md) | Екран документа: панель дій і «More», аркуші, дерево таблиць, сітка, клавіші й F9, інспектор (Issues / History / Info) |
| [04-admin-lists.md](04-admin-lists.md) | Адміністративні переліки: Registries, Units, Consistency issues, Jobs, Templates, Security, Health |

## Як зроблено знімки

- Збірка клієнта `src/Ecr.Web` (`vite build` + `vite preview`) з гілки
  `lane/cloud/batch-4` @ `48824aeb`, браузер Chromium, світла тема, англійська
  мова інтерфейсу, вікно 1280×800 (вузький екран — 500 px).
- Відповіді сервера підмінено тестовими даними. **Назви документів,
  проєктів, довідників, людей і ролей на знімках — приклад, а не дані вашої
  системи**, а знімки зроблено від імені користувача з усіма правами, тому
  в меню видно всі пункти. Ви побачите лише ті пункти й кнопки, на які маєте
  права (`01-navigation.md`, розділ 1).
- Написи на кнопках наведено англійською, як на знімках; переклад російською
  й казахською — у додатку `role-guide.md`.
