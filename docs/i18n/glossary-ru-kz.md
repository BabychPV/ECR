# Глосарій термінів інтерфейсу: en → ru / kz

Єдині переклади ключових термінів каталогу `sys_ecr.UiString`
(`src/Ecr.Infrastructure/Persistence/Sql/09-seed.sql`, секції `#I18N`).
Код мови казахської в сіді — `kz`.

Правило зміни тексту наявного ключа — `CLAUDE.md`, «✎ 2026-09-21»: нове
значення в порції `#I18N` **і** рядок `(ключ, мова, старе, нове)` у секції
«Змінені тексти наявних ключів» (сторож `SeedTextUpdateTests`).

Технічні ідентифікатори (`If-Match`, `rowVersion`, `Registry.EditData`,

в конфігурації.

## Що потребує носія мови

- kz «нобай» для draft — узгоджено в усьому каталозі (≈34 тексти), але термін
  варто підтвердити носієм; альтернатива — «жоба нұсқа» небажана через збіг із
  «жоба» = проєкт.
- kz «кесінді» для snapshot — уживано послідовно (25 текстів); носію перевірити,
  чи не краще «сурет»/«көшірме» в регуляторному контексті.
- kz запозичення, що збігаються з ru («Код», «Формула», «Атрибут», «Логин»,
  «Транспорт», «Трассировка», «Предикат», «Диалект»), прийнятні в казахській
  технічній лексиці, але варто звірити з корпоративним словником замовника.
