## 3. Що НЕ можна втратити при міграції

Перелік речей, які працюють і за які тримаються користувачі:

1. **Робота офлайн.** Файл відкривається без сервера, `CheckServerConnectivity` лише
   вимикає кнопки Save. Дані вводяться, зберігаються локально.
   -> Вимога: offline-режим або хоча б автозбереження чернетки в браузері.
2. **Bulk Save all months** — одна кнопка зберігає 18 аркушів × 12 місяців × N таблиць.
3. **Failover primary/secondary PI Web API.**
4. **Формат експорту значень 1:1** (див. `04-domain-model.md`, п. 8) — інакше нові дані
   несумісні зі старими в AF.
5. **Windows Auth (SSO)** для користувачів — зберігається. Але доступ до PI йде
   **під сервісним обліковим записом**, бо локальні користувачі не мають Windows-ідентичності
   (ТЗ ФВ-6.9); користувач фіксується в аудиті ECR.
6. **Двомовність EN/RU** у довідниках (`Name_EN` / `Name_RU`).
   -> Вирішено: EN + RU + **KZ**; зберігання — JSON `…L10n`, тому нова мова — запис, не міграція.
7. **Excel як формат обміну** — регулятор/суміжники очікують саме `.xlsx`.
   -> Тому **ФВ-4 (експорт/імпорт) обов'язковий**, а не «nice to have».

## 4. Оцінка обсягу

| Метрика | Значення |
|---------|----------|
| Аркушів у шаблоні | 24 (18 звітних) |
| Логічних таблиць | ~90 (сума `templateRow` по всіх аркушах) |
| Різних AF Event Frame Templates | ~90 |
| Атрибутів на шаблон | до ~120 (`Attribute_0010`…`Attribute_1200`) |
| Полів у одному рядку-атрибуті | 7…40 |
| **Оцінка кількості логічних комірок на 1 HSE × 1 рік** | ~90 таблиць × ~30 рядків × ~20 колонок × 12 міс ≈ **650 000** |
| Файлів на рік | «різна кількість» (за словами замовника). Планувати на 100–500 |
| **Оцінка обсягу `CellValue` на рік** | 650 000 × 200 = **до 130 млн рядків/рік** |

> ⚠️ **Це визначає архітектуру зберігання.** 130 млн рядків/рік у `CellValue` —
> це вже питання партиціонування і, можливо, гібридної моделі
> (детальні комірки в JSON-колонці + індексовані «значущі» поля).
> Див. ТЗ §5.1 (модель зберігання + архівування закритих років) і `07-data-model.md` §11.
> Архівування тримає робочі таблиці на обсязі ~1 року — це головний захід проти зростання.
