# Реліз-нотатки: RC8 (rc/2026-10-27) - UI за гібридним макетом (пачка batch-5), фікс фокуса шапки, безпека перезапуску задач і експорту формул

Кандидат RC8 (№8) - **фінальний серверний + UI**, **без міграцій EF** і **без зміни контракту API**. Головне: UI-пачка (`batch-5`) за гібридним макетом `docs/design/hybrid/` (UI-11…UI-42, `D15-01`), яка в RC7 свідомо не входила; фікс шапки сторінки (`PageHeader`) і ледачої підказки (`LazyHint`), що відбирали фокус; три серверні виправлення безпеки (L1-19/20 перезапуск задач, кореляція `/health/ready`, експорт формул CSV/JSON). Попередній пакет - `rc-2026-10-26.md` (RC7, `main` = `af90ecaf`): **RC8 замінює його в частині «UI-пачки в RC7 немає», «експорт формул і L1-19 не закриті», «correlationId у `/health/ready`»** (див. «Known limitations»).

База порівняння - `origin/main` = `af90ecaf` (мерж RC7), вже предок `dev/integration`; перелік змін - `git log origin/main..a7cc2cd3`: 129 комітів, з них 128 без merge (один merge-коміт синхронізації з `main`). Кінчик коду - `a7cc2cd3`. Хеші нижче - коміти `dev/integration`; після нарізки RC хеші в гілці `rc/…` можуть відрізнятися - у заявках спирайтесь на `commit` з `BUNDLE-INFO.txt`. Номер PR нарізки: `#488`.

## Міграції

**Міграцій EF немає** (перевірено: `git diff --stat origin/main a7cc2cd3 -- src/Ecr.Infrastructure/Persistence/Migrations` порожній). Оновлення з RC7 - `deploy-ecr.ps1` без нових змін схеми.

Сід `src/Ecr.Infrastructure/Persistence/Sql/09-seed.sql` **змінено** (`git diff --numstat origin/main a7cc2cd3`: +1467/-8). Підрахунок за вмістом файлу: **395 нових ключів, по одному в кожній мові en/ru/kz (1185 нових пар ключ/мова), жодного ключа не прибрано**; нові секції `COLL:ui…` (en - у основному MERGE, ru/kz - власні порції в блоці I18N). Секція «Змінені тексти наявних ключів» отримала рядки для `search.open` і `search.placeholder` (en/ru/kz, тексти кнопки/поля палітри «Search or run a command» / «Type a screen, a document key or an action…»): оновлюються лише там, де в базі ще стоїть старе значення (правку адміністратора не затирають). Решта видалених рядків diff - перенесення цих ключів, `grants.pickerForbidden` (перенесено, текст той самий) і кома після блоку.

## Known limitations

- **Швидкий набір (T3-01/T4-01):** серії з інтервалом 0 мс між клавішами на повільних/завантажених машинах нестабільні (7 з 20, як RC5-RC7); інтервали 10-120 мс стабільні. Продукт у цій частині не змінювався.
- **R-6:** автор з Deny на аркуш бачить код і назву схованого аркуша у майстрі нового документа (`document-template`, `D-297`); фільтр прихованих аркушів document-template не входить.
- **Дві ролі в одного користувача (D-214), задум, не регресія:** права ролей об'єднуються (union), видимість аркуша - з найвищого гранту; звуження діє лише тоді, коли звужені всі ролі.
- **Обчислювані значення не фільтруються за схованими джерелами:** computed-колонка (напр. C4+C5) дозволяє відновити схований C5 арифметикою; дизайн-питання, беклог.
- **Q-177:** `GET /audit/cells` і `/summary` без `documentId` для власника `Security.ViewAudit` віддають записи по всіх проєктах/аркушах (`D-298`; право - compliance).
- **Булеві канали «існує подане»** (`D-299`, P3). Зразковий документ на проєкт для зведених прихованих частин (можливий хибно-негатив `hasLateEdits`).
- **P3 (беклог/хмарна лінія):** літерали на `ForbiddenPage`; `MutationObserver` у `DetailDrawer`; фонове опитування `useJobsSummary`; `.catch` у `LazyHint`; 43 з 89 UI-комітів без рядка «Макет» у повідомленні.
- **P3 для «Аналізу»:** флейк `RoleNameInListApiTests` (`GET /roles` без нової ролі після 201); `smoke.ps1 -ExistingDatabase -AdminPassword` крок 6 дає 428.
- Старі записи журналів у БД можуть містити сирі повідомлення винятків (не чищено).
- Решта пунктів `rc-2026-10-26.md` і раніших, що не згадані як виправлені, - без змін.

**Прибрано з обмежень RC7 (виправлено в RC8):** UI-пачка відсутня (тепер входить); експорт формул CSV/JSON і перезапуск задач L1-19 не були закриті; `correlationId` у `/health/ready` ≠ id у журналі.
