# Реліз-нотатки: D-401, результат розрахунку знає екземпляр таблиці

## Що змінилося

- Дві таблиці одного документа з однаковим `RowKey` і спільною прив'язкою методології більше не підсумовуються в одну комірку: результат тепер зберігає екземпляр таблиці (`calc.CalculationResult.TableInstanceId`, `NULL` для прогонів до D-401), накладення бере число саме цього екземпляра.
- `GET /documents/{id}/calculation-results` віддає `tableInstanceId`; панель результатів показує колонку «Таблиця».
- Старі результати (без екземпляра) діють за тимчасовим правилом: однакові значення однієї речовини - одне значення, різні - комірка порожня й попередження в журналі. Перерахунок документа записує екземпляр.
- Звіти: колонка `TableInstanceId` доступна лише за явного опису в версії звіту; наявні зрізи й `ContentHash` не змінюються (D-402).

## Оновлення бази

Міграція `D401CalculationResultTableInstance` додає три nullable-колонки `bigint` (метадані, без перебудови даних) і перебудовує `IX_CalculationResult_DocRun` з `INCLUDE (TableInstanceId)`. Перебудова індексу `DROP_EXISTING` читає й пише всю таблицю результатів: на великому обсязі виконувати у вікно обслуговування.
