# Реліз-нотатки: RC23 (rc/2026-11-14): UI-RC — клієнт кольору комірки, projectsQuery, Land L1

UI-RC поверх RC22 (`rc/2026-11-13`, `rc-2026-11-13.md`). Сервер кольору комірки (`PATCH …/cell-styles`, `TableSliceDto.cellStyles`) уже в RC22; тут з'являється клієнт. Хеш вершини фіксується при нарізці `rc/2026-11-14`; тут навмисно не вказаний.

**Обсяг.** Міграцій EF — **немає**. Контракт API (`openapi.snapshot.json`, `schema.d.ts`) **не змінюється**. Сід `Sql/09-seed.sql` — лише секція ключів UI-тексту `L4:cellcolor`.

## Для адміністратора

- Нових прав, ролей і міграцій немає; оновлення з RC22 не змінює наявних даних.
- Власник чи роль, що не має права запису в комірку, кольору не змінить: сервер відмовляє `403 ECR-ACCS-0403` (`deniedCells`), клієнт відкочує зміну й показує тост.

## Що нового

### 1. Клієнт кольору комірки (L4)

- Тулбар сітки: палітри «Заливка» і «Колір тексту» (як в Excel), окремі набори для Light і Dark; «Без заливки» / «Автоматичний колір» знімає користувацький колір (`""` у запиті).
- Шар кольору в сітці: стиль колонки < користувацький колір < умовне форматування < стан (readOnly/calculated/відмова). Користувацька заливка не перекриває умовний формат і стан.
- Запис — `PATCH …/cell-styles` порціями ≤ 1000 комірок; після успіху зріз таблиці інвалідується (рефетч), на `409` — тост «конфлікт» і рефетч.
- Для e2e на елементах палітри є стабільні ознаки.
- e2e `cellColorLive.spec.ts` — **8/8** на реальному стенді (run `38266784994`, гілка `lane/analiz/cellstyle-e2e-2`).

## Відомі обмеження RC23

- **P1-A.** Кнопки кольору активні на `readOnly`/обчислюваних колонках для користувача з правом `Read`: сервер відмовить `403` (`deniedCells`), клієнт відкотить і покаже тост. Серверне поле `canStyle` — у наступному RC.
- Текст «conflict» показується на будь-який `409`, не лише на `concurrentChange`.
- Шару «рядок» (стиль рядка шаблону) у клієнті немає; `isBold` не керується.
- Часткова відмова порції (`403`/`422` на частину комірок) не підраховується в тості; після кожного запису повний рефетч зрізу.
- Штрих (`pattern = hatch`) у сітці не малюється (лише Excel).
- Колір не копіюється при створенні періоду й **немає Undo** (скидання — лише явним «Без заливки»).
- Land на прод-зразках — лише локально (D-392).
- Успадковані з RC22: колір не архівується з даними; стеля 2000 комірок за запит; UI створення правил з областю немає; Excel-правила `expression` не імпортуються автоматично.

## Не входить у RC23

- `cellstyle-canstyle` (серверне поле `canStyle`) і `cellstyle-scope` — в польоті, у наступний RC.
- Малювання штриху в сітці, UI правил з областю, перенос кольору на наступний період, Undo.
