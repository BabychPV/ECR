# Список документів: прогрів карти застарілості (D-430)

Перший запит списку документів за період більше не платить за повний запит карти застарілості: API прогріває
її для поточного й попереднього періодів і двох найновіших періодів з актуальним прогоном після старту та
оновлює кожні 60 с (`Documents:StaleMapWarm:Enabled`, `Documents:StaleMapWarm:IntervalSeconds`, мінімум 10).

Межа видимості: правка довідника іншим процесом (не цим API) потрапляє у відмітки «результати застарілі» до
60 с (кеш відбитка довідників); власна правка й завершені прогони видно одразу. Міграцій і змін контракту немає.

Кільце (LP-45): після старту (у фоні, послідовно, ~1,5 хв) і далі раз на Documents:StaleMapWarm:RingIntervalSeconds (600, мінімум 60) прогріваються ВСІ періоди з актуальним прогоном, а не лише гарячі; записи кільця живуть у кеші до 15 хв (власне вікно SWR), тож перший виклик будь-якого такого періоду - долі секунди. Documents:StaleMapWarm:HotPeriodLimit (2, 1..12) - скільки найновіших періодів з прогоном гріється щохвилини поверх календарних. Не покрито: власна правка комірки піднімає епоху періоду й дає одне синхронне перезавантаження карти; ключі «мої» (staleBy=me, /documents/summary) не прогріваються.
