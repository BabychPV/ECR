# Список документів: прогрів карти застарілості (D-430)

Перший запит списку документів за період більше не платить за повний запит карти застарілості: API прогріває
її для поточного й попереднього періодів і двох найновіших періодів з актуальним прогоном після старту та
оновлює кожні 60 с (`Documents:StaleMapWarm:Enabled`, `Documents:StaleMapWarm:IntervalSeconds`, мінімум 10).

Межа видимості: правка довідника іншим процесом (не цим API) потрапляє у відмітки «результати застарілі» до
60 с (кеш відбитка довідників); власна правка й завершені прогони видно одразу. Міграцій і змін контракту немає.

Кільце (LP-45): після старту (у фоні, послідовно, ~1,5 хв) і далі раз на Documents:StaleMapWarm:RingIntervalSeconds (600, мінімум 60) прогріваються ВСІ періоди з актуальним прогоном, а не лише гарячі; записи кільця живуть у кеші до 15 хв (власне вікно SWR), тож перший виклик будь-якого такого періоду - долі секунди. Documents:StaleMapWarm:HotPeriodLimit (2, 1..12) - скільки найновіших періодів з прогоном гріється щохвилини поверх календарних. Ключі «мої» (staleBy=me, /documents/summary) не прогріваються (див. нижче: тепер це один спільний запис авторів).

Правка комірки (LP-45, D-432): власна правка більше не скидає карту застарілості періоду повністю. Документ позначається «брудним», а наступний читач лікує карту одним вузьким запитом по цих документах (мілісекунди замість 6-36 с повного завантаження); «власна правка видна одразу» зберігається. Пакети перерахунку формул (`Origin = Recalculation`) карту не чіпають. Карти всіх авторів періоду (`/documents/summary`, лічильник «мої», фільтр `staleBy=me`) заповнюються одним запитом `GROUP BY` замість запиту на кожного автора.

Межі: понад 200 «брудних» документів між двома читаннями (масова правка/імпорт через цей API) або усічений журнал позначок - повне синхронне завантаження, як і раніше. Правки іншого процесу (імпорт і збір у Worker) накладка не бачить - як і раніше до 15 с + відбиток прогонів. Прогрів записи авторів не заповнює: перший `/documents/summary` після скидання платить один згрупований запит. Міграцій і змін контракту немає.
