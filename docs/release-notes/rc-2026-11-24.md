## Що нового

### 1. SUBSTANCE_APPLICABLE і довідник LAND_SUBSTANCE_APPLICABILITY (lane `integ-substance-applicability`)

- Нова функція діалекту `SUBSTANCE_APPLICABLE(registry, scope, kind, value)` (рівень Extension, каталог метаданих 35 -> 36): у циклі речовин правило категорії для речовини, не застосовної до рядка, дає порожній ключ — речовину для рядка пропущено (без виходів і помилок, крок трейсу `SubstanceNotApplicable`). Опис — `docs/build/02b-expressions.md`.
- Довідник `LAND_SUBSTANCE_APPLICABILITY`: 816 записів + 10 маркерів (за методологією) зі словників старого C#; файл `land-substance-applicability.json`, у моделі — розділ `substanceApplicability`.
- Етап `Build-LandTemplate.ps1 -Stage SubstanceApplicability` (лише явно, у `All` не входить) обгортає правило категорії чернеток; повтор — 0 змін; `LandParity` обгортку не скидає.
- Тести: `LandSubstanceApplicabilityTests`, `LandSubstanceApplicabilityRuleWrapperTests` (Architecture), `SubstanceApplicableFunctionTests` (Expressions), `SubstanceApplicabilityModuleTests` (Calculations), `SubstanceApplicabilitySqlTests` (Api, реальний SQL).
- Службовий коміт «перегенерація моделі» цієї lane (`a60d02a96`) не взято — модель перегенеровано один раз наприкінці.

- Тести: `LandGtuBridgesModelTests`, `LandGtuBridgesEvaluationTests`.

### 4. LP-21: displayFormat Decimal-колонок Land (lane `analiz/land-displayformat`)

- `Resolve-LandDisplayFormat` (`tools/land/LandTemplateDiff.Lib.ps1`), одна функція для Build і Verify: `displayFormat` моделі (Excel) як є; інакше для Decimal `'0.' + '0' x min(Scale, 6)` (Scale 16 -> `0.000000`, Scale 0 -> `0`).
- Було 595 із 2304 Decimal-колонок з форматом, стало 2304; колонки, де Excel мав General, тепер показують 6 знаків (рішення людини 12.10: зберігаємо до 16 знаків, показуємо за DisplayFormat).
- `Verify-LandTemplate.ps1` до першого Build покаже розбіжності формату на клоні, не побудованому цим кодом. Модель не змінюється.
- Тест: `LandDisplayFormatRuleTests` (3).

### 5. LP-32: перенос версії без змін поданих аркушів (lane `integ-migrate-locked-safe`)

- Подана/затверджена пара документ×аркуш×період переноситься без змін, якщо вихідний аркуш не входить до `VersionMigrationPlan.TouchedSheets`; відмова `sheetsLocked` лише коли план зачіпає подані/затверджені аркуші.
- Адитивне поле контракту `lockedSheets*` у відповіді migrate-version; діалог переносу версії показує перенесені без змін і зачеплені аркуші; ключі `documents.migrateLockedCarried/Affected/Item` (секція сіду `COLL:lp32-locked-safe`).
- Формульні колонки поданих аркушів лишаються зі старими значеннями до Reopen.
- Тести: `DocumentVersionMigrationTests.LockedSafe` (Api), `VersionMigrationLockedSheetsTests` (Application), `VersionMigrationAction.test.tsx` (клієнт).
