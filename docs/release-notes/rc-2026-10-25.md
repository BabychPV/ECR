# Реліз-нотатки: RC6 (rc/2026-10-25) - безпека схованих аркушів (R-7, R-8), безпечні тексти помилок, межа виразу, серверні поля для UI

Кандидат RC6 закриває залишки безпеки схованих аркушів (R-7, R-8, матриця сторожів), прибирає сирі повідомлення винятків з відповідей і журналів (PI-збір, SQL-джерела, перерахунок, outbox/нотифікації, health, розклади збору), вирівнює межу довжини виразу в `POST /expressions/validate` (A4-03b) і додає **серверні поля й маршрути для майбутнього UI** (клієнт їх поки не споживає). **RC6 не містить UI-змін: UI-пачка - у RC7.** Попередній пакет - `rc-2026-10-24.md` (RC5, `main` 30de17d9): він **замінений цим файлом для виправлених пунктів** (див. «Known limitations»). Рішення людини й реєстр: `D-297…D-299` у `docs/tz/10-decisions.md`.

База порівняння - `origin/main` = `30de17d9` (мерж RC5, #485); перелік змін - `git log origin/main..origin/dev/integration` (52 коміти без merge-коміту синхронізації). Хеші нижче - коміти `dev/integration`; після нарізки RC хеші в гілці `rc/…` можуть відрізнятися (cherry-pick) - у заявках спирайтесь на `commit` з `BUNDLE-INFO.txt`. Номер PR нарізки: `#<буде вказано при нарізці>`.

## Міграції

**Міграцій EF немає** (перевірено на `5a19fb79`: `git diff --name-only origin/main origin/dev/integration -- '*Migrations*'` порожній). Сід `src/Ecr.Infrastructure/Persistence/Sql/09-seed.sql` **змінено** (перевірено: `git diff origin/main origin/dev/integration -- src/Ecr.Infrastructure/Persistence/Sql/09-seed.sql`, +19/-4 рядків): (1) **додано ключ** `err.ECR-REQ-0422.consistencySeverity` (en - основний MERGE; ru/kz - секція `COLL:consistency-summary`); (2) **змінено текст наявного ключа** `err.ECR-REQ-0422.expressionTooLong` (en/ru/kz): «Split it into several formulas» -> «Shorten it or split it into several» (ru «Сократите его или разделите на несколько», kz «Оны қысқартыңыз немесе бірнешеге бөліңіз») - через секцію «Змінені тексти наявних ключів» і правку MERGE; оновлюється лише там, де в БД ще стоїть старе значення, тож правки адміністратора з `/admin/ui-strings` не затираються; (3) рядок `coverageEvents.eventsTruncated` (kz) змінено лише технічно: додано кому в кінці, бо після нього дописано нові рядки; текст і значення не змінено. Нічого не видалено. Оновлення - звичайне (`deploy-ecr.ps1`, сід виконує застосунок при старті). Контракт змінено переважно адитивно, з двома винятками (nullable-лічильники, перейменування схеми) - див. таблицю вище.

## Known limitations

Швидкий набір (T3-01/T4-01): інтервали 10-120 мс, стрілки, Ctrl+V/C після стрілки і F2 - стабільні. Серії з інтервалом 0 мс між клавішами на повільних/завантажених машинах нестабільні: 7 з 20 (як RC5).

Нове або змінене в RC6:

- **R-6 (свідомо):** у `document-template` автор, якому на аркуш виставлено Deny, бачить код і назву схованого аркуша (`D-297`; сторож це фіксує).
- **Булеві канали «існує подане»** (D-299): POST recalculate без `sheetDefId`, DELETE, business-key, PATCH header різняться відповіддю 202/422, 204/409, 409/403 залежно від наявності поданого аркуша - прийнято свідомо (P3).
- **Q-177 (D-298):** `/audit/cells` без `documentId` для користувача з `Security.ViewAudit` бачить усе, тепер із кодами й назвами аркушів/таблиць.
- Приховані частини при зведенні (`hasLateEdits` та ін.) рахуються по **зразковому документу на проєкт** - можливий хибно-негатив пізньої правки.
- `SeesAllSheets`: звуження лише періодом без кодів аркушів (`SheetCodes`) не зачеплено.
- У журналі доставки втрачено код відповіді релея (550/500) - лишається тип винятку і код (наслідок SafeErrorText).
- `/audit/cells` з `documentId` фільтрує приховані колонки **після** читання сторінки: `limit`/`nextCursor` можуть давати неповні сторінки (беклог).
- Старі записи журналів у БД можуть містити сирі повідомлення винятків (не чищено).

Лишилось з RC5 без змін (докладно - `rc-2026-10-24.md`):

- Формули методології при збереженні ланцюг >1024 не відхиляють (200); формули глибше 96 рівнів, збережені до оновлення, при перерахунку пропускаються мовчки.
- Backspace, ←, Home у перші мілісекунди після відкриття редактора нічого не роблять; Ctrl+C у вікні переходу - `navigator.clipboard` (без HTTPS і в Safari не копіює).
- A1-05 (задум), одна відповідь 428 на `/public/bootstrap`, A2-03 (Info), Date у тілах CSV/JSON `…T00:00:00`, обрізання шапки xlsx на 50 символах, `/me` лише з глобальними правами, екран зміни пароля без перемикача мови (D-292), сторінки 403/404 не як у макеті (UI-17 хвиля 1).
- `calculation-results`: вихід розрахунку, прив'язаний і до видимої, і до схованої таблиці, не показується звуженому читачу.
- Клієнт: для звуженого читача кнопки за схованим поданим аркушем можуть бути активні; сервер відмовляє загальною причиною.
- Ліміт 200 до фільтра й решта пунктів з `rc-2026-10-20.md`, що не змінилися.

**Прибрано з обмежень RC5 (виправлено в RC6):** R-7 (`hasLateEdits`/`modifiedAt`/`modifiedBy` по прихованих аркушах); сирий `ex.Message` у прогоні збору PI/джерел; `POST /expressions/validate` пропускав вираз 2001-4000.
