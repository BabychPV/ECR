## Що нового

### 1. `CURRENT_SUBSTANCE()` у діалекті методологій

- Нова функція без аргументів, результат — текст: код речовини поточного проходу циклу речовин (`SUBSTANCE_CODE` запису довідника речовин, інакше код запису — той самий код, що суфікс форми B).
- Символ видно в циклі речовин, у вкладеному `REGFIND`, у предикатах агрегатів довідників (`REGCOUNT(…, ROW.X = CURRENT_SUBSTANCE() + '_mass')`) і у формулах імпортованих бібліотек (контекст речовини викликача).
- Конкатенація в діалекті методологій — `+` на двох текстах: `CURRENT_SUBSTANCE() + '_mass'`.
- Без складу речовин у версії (прохід із речовиною `null`) або для речовини без коду — значення `#REF`, а не помилка публікації; решта формул версії рахується.
- Область `Row` із символом — відмова публікації `ECR-CALC-0422` (`rowScopeReferencesSubstance`); версія `Legacy` — `ECR-CALC-0433`, як для всіх розширень.
