# Реліз-нотатки: RC18 (rc/2026-11-06): виправлення оновлення RC16→RC17 і сторожів CI

Кандидат RC18 = RC17 (`main` = `ea47c312`, PR #497) плюс п'ять виправлень, знайдених перевіркою оновлення після вирізання RC17. Попередній пакет — `rc-2026-11-05.md` (RC17).

**Обсяг.** База порівняння — `origin/main` = `ea47c312`. Кандидат нарізано з вершини `dev/integration`, де CI, Evidence і smoke зелені. `git log --no-merges origin/main..HEAD` — 6 комітів (п'ять виправлень і ці нотатки).

## ⚠ Для адміністратора

Нових вимог до оновлення порівняно з RC17 немає. Якщо оновлення з RC16 ще не робили, див. розділ «Перед оновленням» у `rc-2026-11-05.md`: вікно обслуговування, свіжа копія бази, зупинка всіх вузлів. Якщо RC17 уже встановлено — оновлення на RC18 не змінює схему.

## Міграції EF

Нових міграцій немає. Змінено вміст уже наявної `20261009112036_AN80CarryOverInputsAsOfCategoryRuleLength`:
- перед зміною типу `calc.CategoryRule.Expression` на `nvarchar(4000)` `Up` і `Down` скидають неіндексні статистики цієї колонки (`DROP STATISTICS`);
- причина: на живій базі, де SQL Server (чи DBA через `sp_createstats`) уже створив статистику на колонці, `ALTER COLUMN` падав з Msg 5074/4922 і оновлення зупинялось (транзакція відкочувалась, даних не втрачено);
- база, на якій AN80 уже застосовано (RC17), не змінюється; історія міграцій без змін.

## Що змінилося

- **Оновлення з RC16 на живій базі** більше не зупиняється на AN80. Перевірено: свіжа база main, `sp_createstats`, оновлення до RC, smoke 25/25, повторне оновлення (ідемпотентне).
- **`tools/smoke.ps1`** у режимі `-ExistingDatabase` більше не пропускає зміну разового пароля (змінна `$login` збігалась з параметром `$Login`).
- **CI:** сторож `honesty-guard` зараховує `Received.InOrder(...)` (NSubstitute) як перевірку; тест без жодної перевірки і далі червоніє.
- **Документація:** `CLAUDE.md` — обов'язкових перевірок `main` вісім (додано `pr-source`).

Контракт API, `Sql/*.sql` і поведінка для користувачів без змін.

## Відомі обмеження

Без змін відносно RC17 (див. `rc-2026-11-05.md`, розділ «Відомі обмеження»).
