# Реліз-нотатки: RC18 (rc/2026-11-06): лише документація

Кандидат RC18 = RC17 (`main` = `ea47c312`, PR #497) плюс зміни лише в документації. Код, схема БД, `Sql/*.sql`, контракт API і поведінка для користувачів **не змінені**: `git diff --stat origin/main HEAD` — 2 файли (`CLAUDE.md` і ці нотатки). Попередній пакет — `rc-2026-11-05.md` (RC17).

**Чому «коміти» в dev відрізняються від `main`.** Виправлення, знайдені перевіркою оновлення після вирізання RC17 (міграція AN80 зі статистиками колонки, `tools/smoke.ps1`, `honesty-guard`, нотатки RC17), у `main` уже є: їх перенесено в RC17 cherry-pick-ом. У `dev/integration` це ті самі зміни з іншими SHA, тому `git log origin/main..HEAD` показує їх як «нові», а `git diff` — ні.
