# Гібридний макет інтерфейсу ECR Web — еталон для директиви №15

Робочий макет **усіх** екранів застосунку: основа — «Workbench» (прототип A),
плюс смуга показників на сторінках-переліках (з прототипу B). Ванільний
HTML + JS, без збирання й без залежностей. Дані — детерміновані демо
(`ECR.data` у `kit.js`), серверних викликів немає.

⛔ Це **специфікація вигляду й поведінки, не код для копіювання**. У застосунку
те саме реалізується на Mantine — див.
[`../../build/DIRECTIVE-15-FRONTEND.md`](../../build/DIRECTIVE-15-FRONTEND.md).

## Відкрити

```bash
node docs/design/hybrid/serve.js
```

→ <http://127.0.0.1:5197/#/flows> — карта 49 потоків; з неї відкривається будь-який
екран у будь-якому стані. Інший порт: `node docs/design/hybrid/serve.js 5298`.

⚠ Не відкривай `index.html` з диска: це фрагмент без `<head>`, кодування не
оголошене (чому — коментар у `serve.js`).

## Адреса = стан

Кожен стан відкривається посиланням — саме так його знімали на перевірках:

```
#/<маршрут>?theme=light|dark&density=compact|comfortable&state=data|loading|empty|error|forbidden
           &dialog=<id>&panel=<id>&tab=<id>&as=editor|approver|admin
```

Повні переліки (`мітка|адреса`, 444 рядки): [`routes/`](routes/) —
`routes-work.txt` (вхід, документи, групи, помилки), `routes-templates.txt`
(шаблони, конструктор, зв'язки, матриця доступу, правила періодів, порівняння),
`routes-data.txt` (довідники, методики, вирази, одиниці, джерела, мапінг),
`routes-ops.txt` (безпека, періоди, задачі, знімки, журнал, узгодженість,
рядки, стан системи). Документ: `#/documents/DOC-000001`.

⚠ `?state=`, `?as=` і `/flows` — інструменти макета; у застосунок не переносяться.

## Що макет малює, а застосунок — ні (або інакше)

Перелік із рішеннями — [`../../build/DIRECTIVE-15.md`](../../build/DIRECTIVE-15.md) §4.
Коротко: гранти на користувача, `Create partitions`, `Purge jobs`, лічильник
спроб входу, ручні кнопки періоду, Acknowledge, Recall, Migrate.

## Перевірки, які макет пройшов

Дві повні перевірки знімками (усі адреси з `routes/`, світла + темна тема,
ширина 1440 і ~500 px) і прохід кліками в живому браузері. Знайдене й
виправлене: «New document» був активний у закритому періоді; «3 unsaved ·
Retry» на поданому аркуші; три відкриті панелі у Виразах; усі групи дерева
конструктора розгорнуті; підтвердження Retry зникало при зміні розміру вікна;
піктограма Copy переносилась під Correlation ID. Відоме й не виправлене:
нативні поля дат показують локаль браузера (у застосунку — `@mantine/dates`,
рішення D15-09); точна ширина 400 px не знімалась (headless-вікно не вужче ~500).

Мова інтерфейсу макета — англійська (мови продукту `en/ru/kk`); коментарі в
коді — українською, як у всьому репозиторії.
