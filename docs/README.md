(українська — робоча мова розробки, не мова інтерфейсу).

## Довідкова бібліотека

`reference/design/` — **не дублікат** `tz/`. Дев'ять із дванадцяти файлів
`tz/` є зведеннями, які делегують деталь за іменем; частина матеріалу існує
**лише** в `reference/design/` (наприклад, механізм Impact Report —
`design/10-schema-evolution.md` §4).

`reference/backend/` (B00–B23) доповнює, а не повторює: B12–B22 описують
розрахунковий бекенд, якого немає в жодному іншому документі.
`B23-data-flow-diagram.md` — єдиний документ «як збудовано», його дев'ять
збірок звірено з `src/` і вони збігаються.

поставки 2026-09-04: 46 збігаються, 38 змінено. Як інструмент контролю

✎ **2026-09-27: базову версію ТЗ зафіксовано 2026-09-27 рішенням людини**
(«перерахувати суми й зафіксувати нову базову версію ТЗ»). Причина — зміни ТЗ
після попередньої базової версії (`c5a2b8c8`, поставка 2026-09-04):
`ac5f0bab` (D-149…D-184, нові ФВ), `fbea1dd6` (D-185…D-200), а також
`8417916b`, `4973c65e` (D-52a), `463518d7`, `195b4596`, `e0e0ba60`, `b9a59381`,
`fc58598c`, `1516e5d2`, `c6b9377e`, `73b05b04`, `c5ef9f4e`. Цим рішенням
знято й `D14-15` (директива №14: «видалити `CHECKSUMS.txt`») — файл лишається
як датований зріз.

- Перераховано **всі 84** рядки одним правилом: SHA-256 від вмісту файла **так,
  як його зберігає git** (кінці рядків LF), тобто
  `git show HEAD:docs/<шлях> | sha256sum`. До цього маніфест був змішаний:
  43 рядки збігалися з CRLF-копією робочого дерева Windows
  (`core.autocrlf=true`), 11 — з LF, 29 не збігалися ні з чим, один файл
  зник (`build/progress.md`, перенесено в `build/archive/progress.md` — рядок
  переведено на новий шлях). Правило LF не залежить від машини.
- Перевірка на будь-якій машині (PowerShell, з кореня репозиторію):
  `Get-Content docs\CHECKSUMS.txt | % { $h,$p = $_ -split '  ',2; cmd /c "git show HEAD:docs/$p > %TEMP%\b.bin"; if ((Get-FileHash $env:TEMP\b.bin).Hash -ne $h) { $p } }`
  (порожній вивід — збіг; `cmd /c`, бо `>` у Windows PowerShell 5.1
  перекодовує вивід у UTF-16). На LF-чекауті (Linux, CI) — `cd docs && sha256sum -c CHECKSUMS.txt`.
- ⚠ Сторожа в тестах чи CI, що звіряв би ці суми, **немає** (як і
  раніше). Маніфест фіксує базу, але нічого не блокує: наступна правка
  `docs/**` без перерахунку мовчки розведе суми знову.

**Скасований процес.** До 2026-09-08 діяв двовузловий процес із зональними
git-хуками, гілкою `sync` і ескалацією `ASK`. Його знято прямим рішенням
людини (`CLAUDE.md` §«✎ 2026-09-08»). Згадки «ПК-1»/«ПК-2» у чинних
документах — це або банер статусу, або **фактична цитата джерела рішення**
