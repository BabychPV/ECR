### RC-процес (злиття в main)
1. Інтеграційна гілка `lane/integ-*` від свіжого `origin/main` (+ лани `git merge --no-ff`).
2. Локально: збірка, **повний** `tests/Ecr.Architecture.Tests` (1489), `tsc`, бюджет.
3. `git push` → CI + Evidence зелені на SHA.
4. `gh api repos/BabychPV/ECR/git/refs -f ref=refs/heads/rc/<дата>-bN -f sha=<SHA>`; `gh pr create --base main --head rc/<…>` (тіло закінчується `🤖 Generated with [Claude Code](https://claude.com/claude-code)`).
5. e2e-stand (6 шардів) → `gh pr merge N --merge --match-head-commit <SHA>`.
6. Фікс після створення RC: push у лану → CI → `gh api -X PATCH …/git/refs/heads/rc/<…> -f sha=… -F force=false` → e2e → merge.
