Прочитай `.sync-local/NODE`.

- `PK1` → виконай `docs/sync/PROMPT-PK1-CYCLE.md` покроково, не міняючи порядок кроків.
- `PK2` → виконай `docs/sync/PROMPT-PK2-CYCLE.md` покроково, не міняючи порядок кроків.

**Файла немає** — це перший запуск на цій машині, а не помилка. Зареєструй
вузол і повтори цикл:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-node.ps1 -Node PK2
```

(`-Node PK1` на керуючій машині. Та машина, де пишеш код, — `PK2`.)

⛔ Роль не вгадуй і не «припускай за контекстом»: вузол без зареєстрованої
ролі не має права ні писати, ні мержити, бо хуки не знають, яку зону йому
стерегти.

Координація — **два файли на гілці `sync`**: `PK1-LOG.md` (пише керуючий) і
`PK2-LOG.md` (пише виконавець). У чужий не пишеш ніколи. Читати, не
перемикаючи гілки:

```bash
git fetch origin sync
git show origin/sync:PK1-LOG.md
```

Протокол — `docs/sync/10-SYNC-PROTOCOL.md`.
