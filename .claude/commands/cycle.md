Прочитай `.sync-local/NODE`.

- `PK1` → виконай `docs/sync/PROMPT-PK1-CYCLE.md` покроково, не міняючи порядок кроків.
- `PK2` → виконай `docs/sync/PROMPT-PK2-CYCLE.md` покроково, не міняючи порядок кроків.

Файла немає або значення інше → **зупинись**. Не вгадуй роль: вузол без
зареєстрованої ролі не має права ні писати, ні мержити. Виконай
`scripts/install-node.ps1 -Node PK1|PK2`.

Керуючий шар — GitHub Issues і PR. Файли `docs/sync/pk1/**` і `docs/sync/pk2/**`
як стан не використовуй: вони архів.
